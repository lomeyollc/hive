# components/ui

Empty on purpose. shadcn/ui components get generated here by the CLI, e.g.:

```bash
npx shadcn@latest add button card dialog input badge avatar
```

`components.json` at the repo root is already configured (New York style,
neutral base color, CSS variables, `@/` aliases resolved via
`tsconfig.app.json` + `vite.config.ts`).
